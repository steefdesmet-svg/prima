# Walker Pro 0.1.0

Eerste bruikbare versie van Walker Pro.

## Functies

- GPS-locatie bepalen
- Wandelroutes zoeken via meerdere Overpass-servers
- Instelbare straal, minimumafstand en maximumafstand
- Routes op OpenStreetMap tonen
- Dichtstbijzijnde instappunt bepalen
- Google Maps openen met **Breng mij erheen**
- Installeerbaar als Progressive Web App

## GitHub Pages

Activeer in GitHub:

`Settings → Pages → Deploy from a branch → main → /(root)`

Daarna staat de app normaal op:

`https://steefdesmet-svg.github.io/prima/`

Voor GPS is HTTPS vereist. Nieuwe routes zoeken en kaarttegels laden vereisen een internetverbinding.
